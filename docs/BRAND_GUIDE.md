# AgentFlow 品牌与界面规范

## 品牌含义

AgentFlow 表达“智能体沿着可观察、可控制的路径协同运行”。标志将字母 A 与有向图节点结合：顶部节点代表目标，两侧路径代表并行能力，中部节点代表编排与汇聚。

## Logo

- 产品内使用 `frontend/src/components/BrandLogo.tsx`。
- 浏览器图标使用 `frontend/public/agentflow.svg`。
- 图像生成探索稿保存在 `frontend/src/assets/brand/agentflow-mark.png`，矢量版本是产品主标志。
- 标志四周至少保留一个节点直径的安全空间；小于 28px 时只展示图形标。

## 界面原则

1. 工作台优先：界面围绕构建、配置和调试流程组织，不使用营销式装饰。
2. 层级清晰：背景、面板、抬升表面只用三个主要深度层级。
3. 克制发光：光效只用于连接端点、主操作与关键状态。
4. 信息可读：正文不低于 12px，表单控件明确设置字体、行高和状态。
5. 动效有意义：动画用于表达数据流和状态变化，并尊重 `prefers-reduced-motion`。

## 文案语气

短句、直接、以任务为中心。优先使用“保存工作流”“运行”“节点配置”这类明确动作，避免抽象口号和无意义的技术术语堆叠。
